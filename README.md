# Definite

A CLI tool that triages customer support messages into structured JSON. Built for South African banking and telecoms — handles English, Afrikaans, IsiZulu, IsiXhosa, and code-switched messages.

Standard Bank Internship Challenge 2 submission.

---

## Setup

```bash
git clone https://github.com/Letho5/standardbank_triage_system.git
cd standardbank_triage_system
python -m venv venv
venv\Scripts\activate         # Windows
source venv/bin/activate      # macOS / Linux
pip install -r requirements.txt
```
